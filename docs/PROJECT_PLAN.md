# QA Automation Portfolio — Project Plan

## 1. Project Overview

This project aims to build a practical QA Automation Portfolio demonstrating software testing knowledge and automation engineering skills.

The main objectives are:

- Reactivate and strengthen existing QA skills.
- Demonstrate practical UI and API automation capabilities.
- Showcase test framework design and engineering practices.
- Demonstrate Git, CI/CD, and automated test reporting.
- Build a professional GitHub portfolio for QA job applications in Spain.

## 2. Technology Stack

| Area | Technology |
|---|---|
| Programming Language | Python 3.12 |
| UI Automation | Playwright |
| Test Framework | Pytest |
| API Testing | Requests |
| Test Reporting | Pytest HTML / Allure |
| Version Control | Git / GitHub |
| CI/CD | GitHub Actions |

## 3. Project Timeline

### Preparation — November 15–16

- Set up the local development environment.
- Configure the Python virtual environment.
- Install Pytest, Playwright, and Requests.
- Install Chromium.
- Create the GitHub repository and local project structure.

### Week 1: UI Automation — November 17–23

- Build the Playwright + Pytest automation framework.
- Implement 5–8 representative UI test cases using SauceDemo.
- Cover positive and negative scenarios.
- Test login, product selection, shopping cart, and checkout workflows.

### Week 2: API Automation — November 24–30

- Build an API automation framework using Requests and Pytest.
- Implement CRUD test scenarios.
- Add parameterized tests.
- Cover authentication, invalid inputs, missing resources, and response validation.

### Week 3: CI/CD and V1.0 — December 1–7

- Configure GitHub Actions.
- Run automated tests on Push and Pull Requests.
- Generate test reports.
- Preserve failure screenshots and relevant test artifacts.
- Complete the initial README.
- Release Portfolio V1.0.

### Week 4: Testing Documentation — December 8–14

- Create a Test Plan.
- Document Test Cases.
- Write simulated Bug Reports.
- Prepare a Risk Analysis.
- Document a Regression Testing Strategy.
- Use fictional, sanitized business scenarios inspired by practical QA workflows.

### Week 5: Internationalization Testing — December 15–21

- Test Chinese, English, and Spanish language switching.
- Validate date, currency, and number formats.
- Test special characters and encoding.
- Check UI layout changes caused by text length.
- Validate missing translations and language fallback behavior.

### Week 6: Finalization and V2.0 — December 22–28

- Review and improve project structure.
- Refine automated tests and documentation.
- Complete the final README.
- Update the QA resume.
- Release Portfolio V2.0.

## 4. Job Search Strategy

Job searching will run in parallel with portfolio development.

- From November 15: Monitor QA job requirements in Spain.
- From December 7: Start applying using Portfolio V1.0.
- Continue improving the portfolio based on job descriptions and application feedback.

## 6. Project Principles

- Prioritize practical testing skills over unnecessary technology expansion.
- Focus on test quality, maintainability, and clear assertions rather than test quantity alone.
- Use only fictional or sanitized business data.
- Keep project development and job searching running in parallel.
- Deliver working, documented results at each milestone.
